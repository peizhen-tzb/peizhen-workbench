# 陪诊课题工作台

挑战杯课题“中国陪诊服务基本概况与服务信息错配研究”的团队工作台，包括任务进度、资料、会议纪要和讨论。

- 这个仓库只放网页代码，通过 GitHub Pages 发布。
- 数据存在课题组织的私有仓库 `peizhen-data` 里，网页用每个人自己的令牌，通过 GitHub API 读写。
- 网页里的每次修改，都会成为数据仓库的一次提交，可以在那个仓库的提交记录里查到。

第一次使用，请看 [组员设置指南](组员设置指南.md)。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 整个工作台（单文件，不需要构建） |
| `config.js` | 数据仓库名；留空时按 Pages 地址自动推断为 `组织名/peizhen-data` |
| `组员设置指南.md` | 注册账号、生成令牌、登录的步骤 |

## 数据格式

`peizhen-data/data/` 下每类数据存成一个 JSON 文件，格式是 `{"items": [...]}`：`tasks`、`docs`、`meetings`、`threads`（回复存在每条讨论的 `replies` 里）、`milestones`、`members`。上传的文件存在 `peizhen-data/files/`。

两个人同时保存时，后保存的一方会被 GitHub 拒绝（因为文件的 sha 已经变了）。网页会重新读取最新内容，把同一个改动再应用一次后重新提交，所以两个人改的东西都不会丢。
